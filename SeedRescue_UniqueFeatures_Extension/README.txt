SEEDRESCUE+ UNIQUE FEATURES
============================

This is a NON-INVASIVE browser extension for SeedRescue.

It does NOT modify:

- app.py
- engine.py
- frontend files
- backend files
- datasets
- CSV files
- WorldPop data
- OSM data
- Random Forest model
- requirements.txt
- database

NEW FEATURES
============

1. TATTVA Decision Lens
   Seed → Unfolding → Manifestation

2. Resilience Score

3. Weakest-Link Analysis

4. Response Action Queue

5. Live Observed State

6. Operator Decision Notes

INSTALLATION
============

1. Run SeedRescue normally:

   python app.py

2. Open:

   http://127.0.0.1:5000

3. Open Chrome.

4. Go to:

   chrome://extensions

5. Enable Developer mode.

6. Click Load unpacked.

7. Select:

   SeedRescue_UniqueFeatures_Extension

8. Refresh the SeedRescue website.

9. Click:

   ✦ SR+

IMPORTANT
=========

The extension only reads information already visible
on the SeedRescue dashboard.

It does not modify the project's recovery engine.

The Resilience Score and Weakest-Link Analysis are
decision-support heuristics and are NOT replacements
for the project's Random Forest or recovery engine.
